# Global IELTS Home Page

This is a **modern and responsive home page** for a fictional IELTS institute called **Global IELTS**, built using **React.js** and **Tailwind CSS**. The design is mobile-friendly and optimized for a professional look.

---

## **Project Features**

### 1. Navbar
- Sticky navbar with logo and links: Home, Courses, Testimonials, Contact.
- Responsive design with a hamburger menu on mobile.

### 2. Hero Section
- Headline, subtext, and CTA buttons.
- Banner image of students studying.
- Modern gradient background.

### 3. Features Section
- 4 cards showcasing the institute's main services:
  - Speaking Mastery
  - Real Exam Mock Tests
  - AI Band Predictor
  - Personal Mentorship
- Hover effects for interactivity.

### 4. Testimonials Section
- 3 student testimonials with quotes and names.
- Cards with shadows and hover animation.

### 5. Contact Section
- Dedicated section with email and phone info.
- Smooth scroll works when clicking “Contact” link in the navbar.

### 6. Footer
- Quick links for easy navigation.
- Contact info repeated for accessibility.
- Copyright notice.

---

## **Technologies Used**
- React.js
- Tailwind CSS
- HTML & CSS
- JavaScript (for React components)
